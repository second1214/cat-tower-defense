# ねこタワーディフェンス（仮）

虫嫌いのママを、猫が虫から守る縦画面のタワーディフェンス。「My Cat Is So Cute」と同じ世界。

- 下にママ、上から虫が列をまっすぐ下りてくる（5列×9行）。ママまで来るとママの HP が減り、0 で負け
- 猫は1匹、スティック（PC は WASD・矢印）で動かし、近くの虫を自動で攻撃。HP が 0 になると休けいして動けない
- 画面下のカードで、猫のいるマスにオブジェクトを置く（カリカリを使う）。オブジェクトの上で「強化」（E・スペース）
- カリカリは時間では増えない。虫を倒すと落ちる（猫が拾う）。猫の餌皿などは一定時間ごとに生む
- 成長: 猫のレベルとスキルツリー、オブジェクトのかけら合成でレベルアップ、装備（頭・首・胴体、5段階のレアリティ、3つで合成）
- レリック: ステージを初めてクリアするともらえるポイントで解放する永続強化
- 数値はインフレ系（1A = 1000、1B = 100万 … 1Z の次は 1AA）

## 開発

```sh
npm install
npm run dev     # 開発サーバー
npm test        # 成長・戦闘のテスト（成長はステージ100までの強さの伸びも確かめる）
npm run build   # dist/ に出力
```

- `?demo` で手作りデータの戦闘だけ（`?role=ranged|fast|aoe`・`?seed=N`）、`?sprites` で仮の絵の一覧
- 共有の型 `src/core/types.ts`、成長 `src/core/`・データ `src/data/`、戦闘 `src/battle/`（engine は DOM 非依存）、メニュー `src/ui/`
- 絵は今は手描きの仮。`public/sprites/<id>.png` と `public/sprites/manifest.json`（id の配列）で差し替えられる
